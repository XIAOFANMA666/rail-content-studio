# 镜头库 · 本地素材管理

在这台 Mac 的终端运行：

```sh
cd "/Users/xietianyi/Desktop/Agent/media-library"
./start.sh
```

打开 <http://127.0.0.1:8765/>。终端按 Control-C 停止。若端口被占用，运行 `./start.sh --port 8766` 并访问对应端口。首次启动会用本机 Swift 工具链编译媒体助手。数据库、原片与缩略图保存在项目的 `data/` 中。

## 手工验收

1. 在「导入素材」同时选择一张图片和一段短视频，填写导入人与来源。查看两条导入记录，再到「待审素材」查看预览、描述与标签。
2. 重新上传同一个文件并填写不同的来源，确认没有重复的原片，审核详情有两条来源记录。
3. 打开一段素材，填写审核人。缺少授权凭据或使用范围时点击「通过入库」，页面应提示补齐。填写原因后可以保存为「待补证」，它只显示在审核队列里。
4. 使用一条你有权使用的素材，填上授权说明和使用范围并勾选核验。修改标签后通过入库，进入「正式素材库」点击该标签，或搜描述关键词。详情可查看原片、时间范围和来源。
5. 刷新或重启服务，检查审核结果和来源仍可查看。

支持 JPG、PNG、WebP、HEIC、MP4、MOV、M4V，实际解码取决于 macOS 支持。每批最多 20 个文件、150 MB，每个文件最多 50 MB。

自动描述由 Apple Vision 的代表帧分类和画面属性生成。标签可能含英文，模型结果可编辑。建议切点基于画面变化。调整起止时间后，播放范围随之更新，已有描述和缩略图仍来自初次分析的代表帧，请在审核时核对。风险提示覆盖代表帧人脸检测，具体地点、授权、品牌标识、水印和整段画面由审核人确认。

## 第二步：按脚本找镜头

在「正式素材库」打开「按脚本找镜头」。脚本里识别到的铁路专名、地点和画幅可以自动作为必需条件，也可填写地点、线路、画幅或关闭自动识别。必需画面特征匹配审核标签，多个标签用逗号分隔。填入正数的最短视频时长后，图片会被排除。

用采集目录里的英国铁路素材验收：

| 操作 | 预期结果 |
|---|---|
| 搜「早上醒来，窗外就是苏格兰高地的湖泊」，用途选内部选材 | 推荐 Loch Treig 湖泊图，显示湖泊和地点依据，提示清晨和车窗视角尚未确认。 |
| 同一句加必需特征「车窗视角」 | 湖泊图被排除，显示缺少该标签。 |
| 清空必需特征，搜「夜间从 Euston 发车」 | Euston 封面只出现在排除原因中，状态为待补证。 |
| 再搜苏格兰湖泊，把用途切为对外发布 | Loch Treig 被排除，显示未获对外发布审核。 |

排序使用本地中英铁路词表、关键词和审核描述，每次读取最新记录。对外发布需要素材通过入库并由审核人明确确认，已有记录默认仅可用于内部选材。地点和线路的筛选读取审核记录。

## 第三步：从素材缺口找 Commons 候选

1. 在「正式素材库 → 按脚本找镜头」搜一句没有可用结果的脚本。可用「Glenfinnan 铁路高架桥上的列车」，必需特征填「铁路高架桥」，最短视频时长填 3 秒。已验收入库的是图片，因此这组条件仍有视频缺口。
2. 在素材缺口下面点击「在 Commons 找候选」。默认按脚本和条件生成搜索词，也可补充英文搜索词。填了最短视频时长的任务会加视频搜索条件。展开「Commons 采集任务」可以看到查询、下载、重复和网页线索数量。
3. 切到「待审素材」，来源选 Wikimedia Commons。有本地文件的候选可看预览、自动描述和标签。打开审核详情可查看任务条件、Commons 页面、网页作者、上传者、来源说明和许可证。网页声称的信息由审核人核实。
4. 只有网页线索的候选可以标记待补证或拒绝。已手动导入并核实是同一素材的文件，可在该线索里关联，再到文件的审核详情补全记录。
5. 去掉最短时长限制，重新搜索「Glenfinnan 铁路高架桥上的列车」。正式库会推荐已验收的 Glenfinnan Viaduct.jpg。用途改为对外发布时，它会被排除。

单个任务最多记录 6 条候选。图片自动下载上限为 12 MB/文件，视频为 50 MB/文件。支持 JPEG、PNG、WebP、MP4、MOV 和 WebM。WebM 原件保留，后台通过 FFmpeg 生成用于预览和分析的 MP4。缺少开放许可证据、格式不支持、文件过大或下载失败时保留来源线索。同一 Commons 页面和重复文件不会重复创建素材。已有网页线索保留审核记录，重新搜索不会覆盖它，遇到限流可日后手动获取对应文件并关联。

## 首页与审核直达

首页有「导入已有素材」「按脚本找镜头」「网上找素材」三个入口，右上角「待审核」进入全队列。旧版验收说明中的「正式素材库 → 按脚本找镜头」现在可直接从首页进入；正式库关键词和标签浏览在搜索页底部。

- 批量导入 Fort-William-Night.jpg 和 ScotRail-Glenfinnan-360p.mov。若库中已有这两份文件，应显示两项重复；「审核这批素材」只列本批中尚需审核的素材。批次保存到 SQLite，刷新或重启后可从「导入批次历史」继续审核。
- 搜「窗外就是苏格兰高地的湖泊」，点「设为必需：车窗视角」，再点「网上找这个镜头」。采集页应带入脚本、苏格兰、内部选材与车窗条件。
- 点「找候选」后查看本次任务，再点「审核本次候选」。有文件的候选和网页线索均按任务过滤。新版任务可定位去重前已存在的候选。早期只存了重复数量的历史任务，可从最初的采集记录查看对应候选。
- 在审核详情尝试通过一条未核验授权的素材，页面应展开授权区并提示需要补齐。审核通过所需的凭据和发布许可沿用原规则。

## 工作流恢复验收

- 打开「导入已有素材」的「导入批次历史」，选「英国铁路素材 · 工作流验收」，再点「审核这批素材」。批次显示 Fort William 图片和 ScotRail 视频，两项均复用已有素材。刷新或停止并重启服务后，批次仍可打开。
- 打开「网上找素材」中的 Glenfinnan 采集任务 #8。任务关联 6 条已存在候选。进入「审核本次候选」，可点击「重跑原搜索」，用已保存的地点、画幅、用途和必需特征重新筛选，预期返回已获内部选材许可的高架桥照片。
- 下载失败的 Commons 网页线索提供「重试下载」。同一候选已有任务在处理时不会再创建重试。成功后仍关联原网页线索，文件指纹已存在则复用已有素材与审核记录。本地媒体处理失败仍可从批次明细单项重试。
- 重启时，媒体处理中的项目重新排队，采集任务从已保存的候选和查询进度继续。早期任务没有保存完整搜索表单，页面提供「打开历史脚本」，确认条件后可重新搜索。

## 本机配置搜索 Agent

用文本编辑器打开项目目录中的 `search-agent.local.json`。这是后端读取的本机配置文件，文件权限为 600。四个字段填写在同一个 JSON 对象中。

| 字段 | 填写内容 |
|---|---|
| `provider` | 服务商显示名称，用于页面提示 |
| `model` | 服务商提供的模型 ID |
| `base_url` | 兼容 Chat Completions 的接口根地址，包含服务商要求的版本路径，例如 `https://api.example.com/v1` |
| `api_key` | 该服务商的 API Key |

后端会自动追加 `/chat/completions`，所以 Base URL 填到接口根地址。远程使用 HTTPS，本机模型可用环回 HTTP。保存配置后，新任务会读取文件。配置状态只显示是否齐全及服务商、模型名。API Key 留在本机配置文件。

在「网上找素材 → 搜索设置 → 搜索方式」选择 Agent 搜索。固定搜索是默认选项。Agent 首轮复用固定查询，之后根据候选摘要提议换词、查视频版本或停止。每个任务最多查 Commons 3 次、查候选版本 1 次、记录 6 条候选，并受 90 秒任务预算控制。候选版本检查只尝试可本地处理的 MP4 / MOV。模型不可用时继续用剩余固定查询。「Agent 搜索过程」可展开看各轮结果、回退和停止原因。新任务的原条件和各轮进度保存到 SQLite。

## 视频缺口采集

在「网上找素材」直接勾选「仅视频」，也可设最短时长。来自脚本搜索的时长条件会自动带入。固定搜索和 Agent 搜索共用视频筛选。Commons 缺少匹配的视频时补查 Internet Archive，结果与手动提交的来源链接一起进入现有审核队列。手动提交的网页作为线索保存。Internet Archive 候选只有在作者、开放许可、公开可下载文件以及画面条件均有依据时才尝试自动下载。

WebM 转码优先使用系统的 FFmpeg，也可在项目内安装本机版本。Apple Silicon Mac 可在项目目录执行：

```sh
python3 -m pip install --only-binary=:all: --target data/build/video-tools imageio-ffmpeg==0.6.0
```

转码失败后可从采集结果页重试视频处理。自动下载和转码只准备待审核素材，使用范围和对外发布授权由审核人核对。
