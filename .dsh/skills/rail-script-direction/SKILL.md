# 脚本与编导

每个方向提供中文选题、适用人群、一句自然的英文开头和中文对照。突出一个实际的旅客决策，避免大而泛的标题。只借鉴参考的表达思路，重新组织口播和画面。

给编导两到三段按顺序排列的画面，能看出故事怎样推进。使用素材清单中的实际编号作为可选参考，地点未知的素材只能做通用画面。需要订票界面、特定站台或车厢时说明需要什么画面。引导观众去 App 查路线或票种，具体优惠以真实可用条件为准。
