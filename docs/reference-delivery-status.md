## 尚未完成或仍有问题

1. **真实成片未完成**：缺少31个经核验并可用的视频镜头。来源有无关候选、无结果、限流或网络失败；不能笼统写成“网上没有素材”。
2. **图片闭环未完成**：搜图可执行，但图片与分镜的逐一视觉核验、选用、页面回填和图片版视频合成尚未实现；静态图不能证明原连续动作满足。
3. **全文字幕和字体未完全还原**：有OCR辅助代码及本地验证资料，但通用导入仍依赖抽样；逐字时间、精确字体文件、阴影、行距、动态字幕和复杂转场未完整验证/实现。
4. **裁剪能力有限**：自动流程固定中心裁剪。人工候选验证发现偏左/偏右裁剪可能更合适，尚未成为自动匹配和渲染的一致裁剪策略。
5. **连续动作判断有限**：八帧/四帧是抽样；长源未检查区间保留未知，尚无可靠的全源连续区间定位。
6. **声音不是重新生成**：当前保留原参考音轨；未完成同规格重新配音、音乐/音效独立拆分与重建。
7. **审批与运行环境依赖**：未自动冒充审批人；需要本机模型配置、FFmpeg及旧素材库服务。新电脑从零部署和完整真实复刻尚未验收。
8. 项目内Skill已随代码保存；不宣称已安装为账户级个人Skill。

## 源码与运行

主项目运行方式见 `reference-video.md`。`integrations/legacy-media-library/` 保存本次旧素材库源码及测试快照，包含网页静态资源，不包含真实数据库、素材文件、密钥或本机模型配置。当前桥接默认查找主项目同级的 `media-library`；新环境需要将此源码准备为同级目录并自行配置，已有目录应先比较差异，不能盲目覆盖数据。本分支未改变这个默认定位方式。

图片任务命令：`.venv/bin/python -B tools/search_reference_images.py <32位任务ID>`。结果写入对应任务目录的 `image-search-results.json`。该脚本顺序执行、按指纹避免重复提交；单镜头等待有上限，超时/部分结果不能解释为全部完成。

## 验收方法

1. 打开本地工作台 `/#reference`，导入参考并检查分镜表与原片切点。
2. 查看完整搜索计划、逐镜头任务编号和真实搜索轮数；在旧素材库核对来源、下载、画面与授权审批。
3. 遇到失败检查具体来源与错误；恢复应复用任务，不能重复计为新素材或成功匹配。
4. 图片批处理逐项核对截图内容与来源；不要以任务 `done` 代替画面质量验收。
5. 素材齐备后才能验收真实导出：逐镜头内容、动作、景别、帧数、字幕、字体、声音及完整播放。当前该项未通过。
