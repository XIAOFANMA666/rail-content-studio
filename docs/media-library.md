# 素材库执行与验收记录

## 实现范围

本地工作台「素材库」包含找素材、待审批、正式素材库和任务四个工作区。
第一版接入 Pexels 官方视频搜索。支持主动需求和粗剪分句缺口入口。
支持人工搜索词、配置脚本模型后的需求拆解；无模型时仅使用明确标示的本地词表。
搜索最多三组、候选最多二十条、自动分析最多五条，每条最大 100 MB、三分钟。
实际搜索、模型用量和错误保存在任务记录中，未配置密钥时不使用虚构候选。

## 执行流程

1. 在 .env 配置 PEXELS_API_KEY；可选 SCRIPT_* 和支持图像的 VIDEO_*。
2. 安装系统 FFmpeg（ffmpeg 和 ffprobe 均须在 PATH），运行 python3 studio.py。
3. 打开内容资产 → 找素材，填写需求。关闭自动分析时仅收集候选。
4. 下载并分析：检测规格、SHA-256 去重，抽取八张等间隔关键帧。
5. 画面模型逐帧描述、给出需求匹配、风险时间、画质与裁切意见。
6. 模型失败时保留文件检测结果，明确未完成 AI 初审；允许人工检查原片并填写处理依据。
7. 人工确认标签、地点依据、授权及用途说明，填写审批人后批准、要求补充或驳回。
8. 批准后文件先复制到正式目录，再提交素材状态和审批记录。
9. 正式库支持中英文词表扩展、地点、方向、宽度、时长、风险和历史/新增素材筛选。
10. 新素材可用于当前预览镜头，并由正常制作流程召回；停用后不再提供新召回或新替换。

## 存储与边界

- 数据库：output/media-library.sqlite3，包含候选、任务、搜索缓存、审批事件。
- 文件：output/media/candidates/px*/；output/media/approved/px*/。
- 请备份整个 output/；这些本地数据不提交到 Git。
- 候选和正式素材可以通过同一个本地工作台预览；审批只限制进入生产召回，不是用户访问权限。
- 处理人是人工填写的记录，没有接团队身份认证、服务端角色权限或多人审批。
- 重启不会自动重放联网或付费任务；未完成任务改为 interrupted，需明确点击重试。
- 取消在处理边界生效，已发出的模型请求可能仍完成并产生费用。
- 分析只抽样八帧，不能等同于全片内容审核；不自动确认真实地点、人物身份和商业授权。
- 模型风险即使人工接受仍保留；质量 1–5 是人工评价，不伪装为测量结果。
- 使用官方来源接口和署名链接，不抓取社交平台视频，不提供公共素材转售服务。
- 第一版查询是关键词与中英文词表扩展，没有向量检索、无人值守定时采集或 Pixabay 实现。
- 历史 53 条素材保留原标注，不补造审批记录；历史未知技术规格不能通过指定规格筛选。
- 静态 index.html 保留历史素材展示，联网、审批和新素材文件只在本地工作台可用。

## 本轮发现与修复

1. 镜头可能选择比所需时长更短的素材：召回增加时长条件；候选不足时明确提示并重复编排，无法满足时停止并要求补充素材。
2. 新素材停用后可能使旧工程重写失败：只为已有镜头保留可读取的素材快照，禁止把快照用于新增替换。
3. 损坏下载文件会一直阻塞重试：检测失败时丢弃该缓存文件，让重试重新下载。
4. 后续搜索词失败会使任务丢失已找到候选：逐组保存候选，按搜索词记录错误，保留已有结果。
5. 已有候选重复命中新需求时初审仍按旧需求分析：自动分析改用当前搜索任务的需求。
6. 短配音下花字超出分句边界造成轨道重叠：花字时长限制在对应分句内，已用真实工程生成覆盖验证。

真实来源搜索、真实模型初审、浏览器视觉和剪映客户端验收仍未通过；本轮没有提供这些环节的费用、准确率或成功率数值。
