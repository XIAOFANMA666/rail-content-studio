# 参考视频导入与复刻

本地工作台新增「参考视频复刻」，入口 `/#reference`。导入 MP4、MOV、M4V 后后台自动执行：文件检查 → 读取复刻 Skill → 切点检测与分镜/字幕分析 → 正式素材库候选匹配 → 按参考时间轴合成 MP4。声音保留参考音轨并重新编码为 AAC。

## 使用

1. 用项目 Python 环境启动 `studio.py`，在侧栏进入参考视频复刻。
2. 首次在页面配置支持图片的 OpenAI 兼容模型接口地址、模型名称、API Key。联网补库使用 Pexels 或本机扩展素材库（Commons 图片/视频、Archive 视频）。密钥只写本机 `.env`，页面不会回显。
3. 选择参考视频，点击「导入并开始复刻」。限制为100MB、3分钟、最大3840分辨率、1–60fps和40个检测镜头。
4. 查看后台状态、镜头表、素材匹配与差异。缺口自动提交旧素材库搜索；下载后先核对实际画面，通过后等待真实审批并自动继续。已授权的补库任务在重启后恢复观察；运行中的解析和渲染仍暂停等待继续。
5. 成功后可并排播放参考和生成视频，下载视频与验收记录。解析表支持编辑后重新生成。可以停止任务，已发出的模型或渲染会在当前步骤结束后停止。

## 当前实现与验收口径

- 真正读取 `skills/replicate-reference-video/SKILL.md`，保存其摘要；每个镜头解析后保存恢复检查点。
- 使用 FFmpeg 逐帧解码，按区域差分和局部运动基线检测硬切，抑制局部图形变化与单帧闪光。每镜头四帧作为视觉分析输入，字幕时间和字体身份属于推断；短字幕或复杂转场可能漏检，不能承诺任意参考完全一致。
- 既有库优先，联网搜得的新审批素材优先参与补库匹配。匹配帧采用与导出一致的中心裁剪；保存拒绝结果，避免反复调用同一候选。
- 对候选八帧初筛后，对选定区间四帧复核；这仍是抽样模型判断，不能冒充全片人工核验。
- 分镜区间固定为参考时间轴，不根据新配音长度重新分段；不会循环素材或冻结尾帧填时长。
- 当前渲染支持硬切、静态字幕（文字、中心位置、字体名称、字号、字重、颜色、描边）与原音轨。遇到已识别的其他转场/字幕动画会暂停并明确原因。阴影、行距、精确字体文件匹配及复杂动效仍未完整实现。
- 生成结果标记「预览待验收」，不会自动标记为与参考完全一致。

## 工程入口

- `reference_video.py`：任务状态、解析、匹配、补库、恢复、取消、渲染与验收数据。
- `reference_http.py`：导入、状态、历史、继续、取消、配置和媒体分段读取。
- `reference_settings.py`：配置校验与私有原子保存。
- `reference_cuts.py`：本地逐帧硬切检测与可审计指标。
- `reference_legacy_media.py`：桥接既有图片/视频素材库，真实提交任务与读取审批片段。
- `reference_material_search.py`：完整分镜搜索计划、指纹去重、历史迁移、有限并发和同任务网络恢复。
- `reference_candidate_review.py`：下载后内容筛选与区间复核，不改变素材库审批或许可状态。
- `reference_overlays.py`：参考图形图层验证与合成。
- `web/template.html`：工作台入口和单文件页面交互。
- 每次任务存于 `output/reference-jobs/<id>/`，含原视频、job.json、reference-spec.json、match-plan.json、library.json、字幕、生成MP4及验收数据；不覆盖原话题粗剪结果。

## 旧素材库闭环与验收

目标固定为：导入参考视频，按原镜头语义、顺序、准确帧数、字幕与声音规格生成替代视频；具体主体外观允许不同，不用无关镜头或静态图补动态缺口。

缺口搜索读取完整制作规则及 `material-search-policy.json`，优先调用相邻 `media-library` 的真实搜索 Agent。短英文查询负责检索，完整主体、动作、景别、场景、方向、构图与时长留在请求中供后验。网页没有这些描述不等于画面不符，可获取的候选进入内容筛选。

同一完整语义计划最多两个外部任务，每个任务最多三轮查询。历史不完整实验的任务和候选保留，但不冒充当前完整计划已经搜索。响应丢失先按指纹对账；429和临时网络失败恢复原任务。等待预算从该任务首次网络失败开始，旧实验等待不消耗新计划预算。同一来源在所有历史任务间共享冷却；Archive 补源等待不阻塞健康的 Commons 主搜索，未知来源保守处理，服务端等待不会缩短。

下载后校验原文件哈希与真实视频轨道，支持 WebM/OGV。按最终裁切抽八帧，初筛通过后复核准确区间的四帧。每镜头最多自动检查五个素材，每次工作最多两个模型请求，内容路径关闭模型内部重发。未知和错误不当作内容不符；终止错误不阻塞其它补搜。长源抽样不符合不表示整片无合适片段。内容通过仍须真实审批才能导出。

验收方法：

1. 在 `/#reference` 导入参考，检查分镜表和逐镜头搜索状态；`material-search-plan.json` 应保留完整条件、准确帧数和策略哈希。
2. 检查旧任务的 `external_request_id`、`reference_context`、`script` 和 `fullspec`；同一指纹重复提交应返回原任务。
3. 页面任务卡核对实际搜索轮数和 Agent 调整次数，并对照旧任务的 `result.planning` 与 `result.rounds`；0次或缺失不表示模型已改词。分别核对网页线索、已下载、内容核验和真实审批；抽样待定位与预算用完不会显示成内容已通过。
4. 不符动作、景别、场景或时长的候选不得进入 `matches`。长源未检查部分必须保留未知。
5. 审批后观察素材回到对应原分镜匹配；全部镜头通过才渲染。下载成功或合成夹具通过不能抵扣真实成片验收。
